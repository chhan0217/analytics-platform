## 3. 발견 및 수정한 버그

- **parseDateRange**: `2026-01-01` 같은 날짜만 넘기면 `Instant.parse` 실패 → `parseInstant()` 헬퍼로 `T00:00:00Z` 자동 보충
- **퍼널 API 테스트**: `steps`에 문자열 배열 대신 `FunnelStep` 객체 배열 필요 (API 자체는 정상, 테스트 요청 형식 오류)
