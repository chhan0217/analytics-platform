## 3. 의사결정

- **플랫폼별 텍소노미**: 방법 1 채택 (프로젝트 단위 공유, 속성 값만 플랫폼별 허용)
- **screen_id**: AppRoute 경로를 그대로 사용 (파라미터는 SDK에서 자동 제거)
- **화면 체류시간**: SDK에서 `screen_leave` 이벤트 전송 방식 (방법 B, 정확한 방식)
- **`!!` 사용 금지**: nullable은 `?: throw ApiException(...)` 또는 안전 호출로 처리
- **DB 초기화 원인**: `./gradlew :backend:build`의 테스트가 실제 DB의 `cleanDatabase()` 실행 → `-x test`로 빌드하면 방지 가능

## 4. 검증 결과

- SDK `stripRouteParameters` 단위 테스트 5개 통과
- Backend build 성공 (ktlint, lint 통과)
- 이벤트별 집계 API: `button_click: 4건`, `screen_view: 3건` 등 정상 응답
- 속성별 분석 API: `button_id`별, `screen_id`별, `method`별 분석 정상
- 화면 체류시간: `screen_leave` 14건 수집, 평균 체류시간 대시보드 표시 확인
- 채비 앱 실기기: screen_id 파라미터 제거 확인, screen_leave 전송 확인

## 5. 발견한 이슈 및 수정

- **`extractJsonField` 정규식**: 문자열 값만 추출하는 버그 → 숫자/불리언도 추출하도록 수정
- **텍소노미 상세 API**: properties 필드 미포함 → `findById()`에서 속성 목록 포함하도록 수정
- **테스트 DB 초기화**: `./gradlew :backend:build` 시 테스트가 실제 DB를 초기화 → 셋업 스크립트로 복구 간소화
