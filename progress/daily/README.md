# Daily Work Logs

하루 작업을 마무리할 때 날짜별로 저장하는 기록이다.

Phase별 상세 체크리스트는 상위 `progress/day-XX-phaseX.md` 문서에서 관리하고, 이 폴더에는 해당 날짜에 실제로 진행한 작업과 검증 결과를 요약한다.

## 파일 규칙

- 파일명: `YYYY-MM-DD.md`
- 같은 날짜에 기록을 추가할 때는 기존 파일을 갱신한다.
- 커밋된 작업과 미커밋 작업을 구분한다.
- 실행하지 않은 빌드나 테스트를 성공으로 기록하지 않는다.
- 실패한 검증은 실패 원인과 남은 조치를 함께 기록한다.
- 시크릿, 수집 키, 사용자 식별값 등 민감한 값은 기록하지 않는다.

## 기록 항목

1. 작업 요약
2. 완료 및 커밋된 작업
3. 진행 중인 미커밋 작업
4. 실행한 검증과 결과
5. 문서 및 의사결정
6. 알려진 제한과 다음 작업
