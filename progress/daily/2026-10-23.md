## 4. 주요 구현 내용

### KMP SDK
- expect/actual로 Android/iOS 플랫폼 context 수집 (os, device, locale, timezone)
- session_start/session_end 자동 전송 (세션 전환, 초기화, 포그라운드 복귀)
- onBackground: flush만 수행 (session_end 보내지 않음 — 업계 표준)
- onForeground: 세션 만료 시에만 session_end + session_start
- kotlin.uuid → expect/actual randomUuid() 전환 (Kotlin 2.0.0 호환)
- Maven Local 배포: publishLibraryVariants("release")

### Backend
- session_end 이벤트 수신 시 analytics_sessions.ended_at 업데이트
- anonymous_id 세션 조회 시 anonymous_identities에서 실제 ID 역조회

### Web Dashboard
- 헤더에 조직/프로젝트 드롭다운 (localStorage 영속화)
- 사이드바: 분석(개요/이벤트/화면/퍼널/여정/사용자) + 설정(앱/텍소노미)
- 개요 페이지: 핵심 지표 카드 + 화면별 통계
- 세션 목록: 활성/종료/종료(추정) 상태 표시
- 모든 페이지 ProjectContext 기반으로 전환

### 문서
- 설계 문서 6개 전수 조사 후 현재 구현에 맞게 갱신
- 기능 로드맵 (필수 기능 10가지 현황)
- SDK 연동 가이드 (설치~초기화~Navigation~버튼~식별)
- 온보딩/로그인 이벤트 설계서
