## 4. CI 확인 결과

KMP SDK CI 워크플로는 다음 명령으로 Android, iOS 3개 타깃과 Compose 어댑터를 한 번에 검증한다.

```bash
./gradlew clean :sdk:analytics-kmp:build :sdk:analytics-compose:build
```

확인한 최근 성공 실행 시간은 약 7분 17초~9분 37초였다. 실행 중 하나의 단계별 시간은 다음과 같다.

| 단계 | 소요 시간 |
|---|---:|
| Gradle/Konan 캐시 복원 | 약 1분 24초 |
| KMP SDK + Compose 클린 빌드 | 약 5분 52초 |
| 전체 작업 | 약 7분 31초 |

주요 병목 후보:

- macOS runner에서 Android와 Kotlin/Native iOS 타깃 전체 검증
- Android/iOS 작업을 하나의 Job에서 처리
- 큰 Gradle/Konan 캐시 복원
- 저장소 전체 Gradle 파일을 사용하는 넓은 캐시 키
- 매 실행의 `clean` 사용

## 5. 문서 및 의사결정

KMP SDK CI 최적화 검토 문서를 작성했다.

- 문서: `docs/decisions/kmp-ci-optimization-proposal.md`

제안한 적용 순서:

1. 동일 브랜치의 이전 CI 자동 취소
2. `clean` 제거 효과 측정
3. Gradle 캐시 방식 개선
4. PR 빠른 검증과 전체 iOS 검증 분리
5. Android/common과 iOS Job 병렬화
6. 변경 경로에 따른 조건부 iOS 검증

`develop`과 `main`에서는 전체 Android/iOS 검증을 유지하는 방향을 권장한다.
