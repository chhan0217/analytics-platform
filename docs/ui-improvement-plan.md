### 1-1 상세: Overview 증감률 뱃지

#### 현재 상태

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 이벤트        │ │ 세션          │ │ 사용자        │
│ 1,234        │ │ 567          │ │ 89           │
└──────────────┘ └──────────────┘ └──────────────┘
```

숫자만 표시되어 "이게 많은 건지 적은 건지" 맥락을 알 수 없다.

#### 개선 후

```
┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
│ 이벤트            │ │ 세션              │ │ 사용자            │
│ 1,234            │ │ 567              │ │ 89               │
│ ▲ +12.5% vs 이전  │ │ ▼ -3.2% vs 이전   │ │ ▲ +8.0% vs 이전   │
└──────────────────┘ └──────────────────┘ └──────────────────┘
```

#### 구현 방식

**1단계: 백엔드 — 이전 기간 데이터 함께 반환**

현재 Overview API (`GET /analytics/overview?start_date=...&end_date=...`)는 해당 기간의 집계만 반환한다.
이전 기간 집계를 추가로 반환하도록 수정한다.

```
요청: start_date=2026-10-24, end_date=2026-10-30 (7일)
이전 기간 자동 계산: 2026-10-17 ~ 2026-10-23 (동일 길이)
```

응답 변경:
```json
{
  "total_events": 1234,
  "total_sessions": 567,
  "total_users": 89,
  "previous": {
    "total_events": 1097,
    "total_sessions": 586,
    "total_users": 82
  }
}
```

**수정 파일:**
- `AnalyticsService.kt` — `overview()` 함수에 이전 기간 쿼리 추가
- `AnalyticsDto.kt` — `OverviewResponse`에 `previous` 필드 추가

**2단계: 프론트엔드 — Card 컴포넌트 증감률 표시**

Card 컴포넌트에 `previous` prop을 추가하고 증감률을 계산하여 표시한다.

```tsx
// 변경 전
<Card label="이벤트" value={overview.total_events.toLocaleString()} />

// 변경 후
<Card
  label="이벤트"
  value={overview.total_events}
  previous={overview.previous?.total_events}
/>
```

Card 컴포넌트 내부:
```tsx
function Card({ label, value, previous }: {
  label: string;
  value: number;
  previous?: number;
}) {
  const change = previous ? ((value - previous) / previous) * 100 : null;
  const isUp = change !== null && change > 0;
  const isDown = change !== null && change < 0;

  return (
    <div style={cardStyle}>
      <div style={labelStyle}>{label}</div>
      <div style={valueStyle}>{value.toLocaleString()}</div>
      {change !== null && (
        <div style={{
          fontSize: 12,
          fontWeight: 600,
          marginTop: 4,
          color: isUp ? "#10b981" : isDown ? "#ef4444" : "#6b7280",
        }}>
          {isUp ? "▲" : isDown ? "▼" : "—"} {Math.abs(change).toFixed(1)}% vs 이전
        </div>
      )}
    </div>
  );
}
```

**수정 파일:**
- `OverviewPage.tsx` — Card에 previous 전달
- `api/types.ts` — OverviewData에 previous 타입 추가

### 4-1 상세: 화면 분석 히트맵 색상

#### 현재 상태

```
| 화면       | 방문 수 | 고유 사용자 | 평균 체류시간 | 이탈 수 | 이탈률  |
|-----------|--------|-----------|------------|--------|--------|
| onboard   | 150    | 89        | 12초        | 5      | 3.3%   |
| login     | 120    | 75        | 45초        | 30     | 25.0%  |
| register  | 40     | 35        | 2분 30초    | 20     | 50.0%  |
| mypage    | 200    | 100       | 5초         | 80     | 40.0%  |
```

모든 셀이 동일한 스타일. 이탈률 50%인지 3%인지 한눈에 구분이 안 된다.
현재는 이탈률 > 50%일 때만 빨간색 텍스트(`#dc2626`)로 표시하는 단순 분기만 있다.

#### 개선 후

```
| 화면       | 방문 수 | 고유 사용자 | 평균 체류시간  | 이탈 수 | 이탈률       |
|-----------|--------|-----------|-------------|--------|-------------|
| onboard   | ████   | 89        | 12초         | 5      | 3.3%  🟢    |
| login     | ███    | 75        | 45초 (주의)   | 30     | 25.0% 🟡    |
| register  | █      | 35        | 2분 30초 🔴  | 20     | 50.0% 🔴    |
| mypage    | █████  | 100       | 5초          | 80     | 40.0% 🟠    |
```

**색상이 적용되는 컬럼 3개:**
- **방문 수**: 가로 바 (상대 비율)
- **평균 체류시간**: 배경색 그라데이션 (너무 짧거나 길면 주의)
- **이탈률**: 배경색 그라데이션 (높을수록 빨강)

#### 구현 방식

**프론트엔드만 수정** — 백엔드 변경 없음

**1) 이탈률 히트맵 색상**

셀 배경색을 이탈률 값에 따라 그라데이션으로 적용한다.

```
0~10%   → 연한 초록 배경 (#f0fdf4) + 진한 초록 텍스트 (#15803d)
10~25%  → 연한 노랑 배경 (#fefce8) + 진한 노랑 텍스트 (#a16207)
25~40%  → 연한 주황 배경 (#fff7ed) + 진한 주황 텍스트 (#c2410c)
40%~    → 연한 빨강 배경 (#fef2f2) + 진한 빨강 텍스트 (#dc2626)
```

```tsx
function bounceRateStyle(rate: number): React.CSSProperties {
  if (rate < 0.1) return { background: "#f0fdf4", color: "#15803d" };
  if (rate < 0.25) return { background: "#fefce8", color: "#a16207" };
  if (rate < 0.4) return { background: "#fff7ed", color: "#c2410c" };
  return { background: "#fef2f2", color: "#dc2626" };
}
```

**2) 평균 체류시간 히트맵 색상**

체류시간이 너무 짧으면(빠른 이탈 의심) 주의, 적절하면 정상, 너무 길면(UX 문제 의심) 주의.

```
0~3초     → 연한 빨강 배경 (#fef2f2) — 너무 짧음, 이탈 의심
3~10초    → 연한 노랑 배경 (#fefce8) — 짧은 편
10초~2분  → 연한 초록 배경 (#f0fdf4) — 적정 범위
2분~5분   → 연한 노랑 배경 (#fefce8) — 긴 편
5분~      → 연한 빨강 배경 (#fef2f2) — 너무 길음, UX 문제 의심
```

```tsx
function durationStyle(ms: number | null): React.CSSProperties {
  if (!ms) return { color: "#ccc" };
  const sec = ms / 1000;
  if (sec < 3) return { background: "#fef2f2", color: "#dc2626" };
  if (sec < 10) return { background: "#fefce8", color: "#a16207" };
  if (sec < 120) return { background: "#f0fdf4", color: "#15803d" };
  if (sec < 300) return { background: "#fefce8", color: "#a16207" };
  return { background: "#fef2f2", color: "#dc2626" };
}
```

**3) 방문 수 가로 바**

방문 수를 상대적으로 비교할 수 있도록 셀 내부에 배경 바를 추가한다.
전체 화면 중 최대 방문 수를 기준으로 비율을 계산한다.

```tsx
const maxViewCount = Math.max(...screens.map(s => s.view_count));

// 셀 내부
<td style={{ padding: 8, position: "relative" }}>
  <div style={{
    position: "absolute",
    left: 0, top: 0, bottom: 0,
    width: `${(s.view_count / maxViewCount) * 100}%`,
    background: "#EEF2FF",
    borderRadius: 4,
  }} />
  <span style={{ position: "relative" }}>{s.view_count}</span>
</td>
```

**4) 컬럼 클릭 정렬 (4-2)**

테이블 헤더 클릭 시 해당 컬럼 기준 오름차순/내림차순 정렬한다.

```tsx
const [sortKey, setSortKey] = useState<string>("view_count");
const [sortDir, setSortDir] = useState<"asc" | "desc">("desc");

const sorted = [...screens].sort((a, b) => {
  const va = a[sortKey], vb = b[sortKey];
  return sortDir === "desc" ? vb - va : va - vb;
});

// 헤더
<th onClick={() => toggleSort("view_count")} style={{ cursor: "pointer" }}>
  방문 수 {sortKey === "view_count" ? (sortDir === "desc" ? "▼" : "▲") : ""}
</th>
```
