# 2026-10-30 데일리 기록

## 오늘 작업 요약

### 1. 세션 리플레이 — React 컴포넌트 화면 구현

채비 앱의 실제 Compose 화면을 참고하여 React 컴포넌트로 와이어프레임 9개 화면을 구현했다.
기존 JSON DSL + LayoutWireframe 렌더러 방식을 폐기하고 React 컴포넌트 방식으로 전환했다.

**구현 화면:**
| screen_id | 화면 | 플로우 |
|-----------|------|--------|
| splash | 스플래시 | 온보딩 |
| onboard | 온보딩 | 온보딩 |
| login | 로그인 | 로그인 |
| find_id | 아이디 찾기 | 로그인 |
| reset_password | 비밀번호 재설정 | 로그인 |
| register_term | 약관동의 | 회원가입 |
| register_pass | 본인인증 | 회원가입 |
| register_input | 정보입력 | 회원가입 |
| register_complete | 완료 | 회원가입 |

**디렉토리:** `web-dashboard/src/features/screens/layouts/`

### 2. 세션 리플레이 — 인터랙션 하이라이트

`Highlight` 공통 컴포넌트를 만들어 SDK 이벤트의 `element_id`와 화면 컴포넌트의 `data-element-id`를 매칭하도록 구현했다.

- 재생 중 `button_click` 이벤트 도달 시 해당 요소에 파란 테두리 + 글로우 펄스 애니메이션 (0.6초)
- 이벤트 패널에서 클릭 시 즉시 하이라이트 트리거
- 화면 전환 시 페이드아웃(0.15s) + 슬라이드인(0.2s) 애니메이션 적용
- 모든 화면 컴포넌트에 `ScreenProps { highlightId }` 인터페이스 적용

### 3. 앱 화면 미리보기 — 플로우별 그룹핑

앱 화면 페이지의 미리보기를 플로우별(온보딩/로그인/회원가입)로 그룹핑하여 표시하도록 변경했다.
각 화면 사이에 화살표(→)와 스텝 번호 뱃지를 표시한다.

기존 목록 탭, 생성/삭제/편집 기능, JSON 에디터를 제거하고 플로우별 미리보기만 남겼다.

**삭제된 파일:**
- `ScreenEditPage.tsx` — JSON 에디터 페이지
- `LayoutWireframe.tsx` — JSON DSL 렌더러
- `WireframeRenderer.tsx` — SDK 캡처 기반 렌더러

### 4. SDK 채비 앱 적용

채비 앱(`Infra_AOS_NATIVE`)에 Analytics SDK를 연동했다.

- `ChaeviApplication.kt`에 `Analytics.initialize()` 추가
- `flushIntervalMs = 10초`로 설정
- 8개 화면에 `Analytics.trackScreen()` 추가
- 16개 버튼에 `Analytics.track("button_click", { element_id })` 추가
- Ingestion Key 신규 발급 (`ink_dc63a49d...`)
- `settings.gradle.kts`에 `mavenLocal()` 추가 필요 안내

### 5. 대시보드 UX 통일

공통 컴포넌트 3개를 신규 생성하고 전체 페이지에 적용했다.

| 컴포넌트 | 용도 | 적용 페이지 |
|---------|------|------------|
| `LoadingState` | 스피너 + 텍스트 | 10개 페이지 |
| `ErrorState` | 에러 아이콘 + 메시지 + 재시도 | 10개 페이지 |
| `EmptyState` | 아이콘 + 제목 + 설명 | 7개 페이지 |

기존에 누락됐던 페이지들(RetentionPage, TaxonomyPage, UsersPage, OrganizationsPage, ProjectsPage, ApplicationsPage)에 로딩/에러/빈 상태 처리를 추가했다.

### 6. Overview 증감률 뱃지

개요 페이지의 KPI 카드에 이전 기간 대비 증감률 표시를 추가했다.

**백엔드 변경:**
- `OverviewResponse`에 `previous` 필드 추가 (동일 길이 이전 기간 자동 계산)
- `ActiveUsersResponse`에 `previous_dau/wau/mau` 필드 추가

**프론트엔드 변경:**
- `Card` 컴포넌트를 `KpiCard`로 교체 (증감률 계산 + 색상 뱃지)
- 증가: 초록 `▲ +X.X% vs 이전`, 감소: 빨강 `▼ -X.X% vs 이전`, 이전 0: `NEW`

### 7. 화면 분석 히트맵 색상 + 정렬

화면 분석 테이블에 히트맵 색상과 컬럼 정렬을 추가했다.

| 요소 | 적용 방식 |
|------|-----------|
| 방문 수 | 연한 인디고 가로 바 (최대 방문 수 대비 상대 비율) |
| 평균 체류시간 | 배경색 (0~3초/5분+ 빨강, 3~10초/2~5분 노랑, 10초~2분 초록) |
| 이탈률 | 배경색 (0~10% 초록, 10~25% 노랑, 25~40% 주황, 40%+ 빨강) |
| 컬럼 정렬 | 헤더 클릭으로 오름차순/내림차순 토글 (▲▼ 표시) |

### 8. 리텐션 역순 정렬

리텐션 히트맵 테이블과 CSV 내보내기를 최신 코호트가 맨 위에 오도록 역순 정렬했다.
