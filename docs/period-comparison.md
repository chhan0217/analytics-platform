# 기간 비교 설계

> 작성일: 2026-10-28

## 1. 목적

시계열 추이 페이지에서 "이번 기간 vs 이전 기간"을 나란히 비교한다.
서버 변경 없이 대시보드에서 기존 trend API를 두 번 호출하여 구현한다.

## 2. 동작 방식

사용자가 10/21~10/28 (7일)을 선택하면:
- **이번 기간**: 10/21 ~ 10/28 → trend API 호출
- **이전 기간**: 10/14 ~ 10/21 → 동일한 길이로 자동 계산하여 trend API 호출

두 결과를 하나의 차트에 겹쳐서 표시한다.

## 3. 서버 변경

없음. 기존 `GET /analytics/trend` API를 그대로 사용한다.

## 4. 대시보드 변경

### TrendPage.tsx

#### UI 추가
- "기간 비교" 토글 스위치 추가
- 켜면 이전 기간 데이터를 자동으로 함께 조회

#### 차트 표시
- 이번 기간: 실선
- 이전 기간: 점선 (동일 색상, 투명도 낮춤)
- X축 레이블은 이번 기간 날짜 기준, 이전 기간은 상대 위치로 정렬

#### 변화율 요약
차트 위에 요약 카드 표시:

```
이벤트: 840건 → 620건 대비 +35.5% ↑
세션:   120건 → 105건 대비 +14.3% ↑
사용자:  45명 →  38명 대비 +18.4% ↑
```

## 5. 이전 기간 계산 규칙

| 선택 기간 | 이전 기간 |
|----------|----------|
| 10/21 ~ 10/28 (7일) | 10/14 ~ 10/21 |
| 10/01 ~ 10/31 (30일) | 09/01 ~ 09/30 |
| 10/28 ~ 10/28 (1일) | 10/27 ~ 10/27 |

공식: 이전 시작 = 시작 - (종료 - 시작 + 1일), 이전 종료 = 시작 - 1일
